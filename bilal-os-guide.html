خطوات البناء
01
تثبيت الأدوات المطلوبة
تحتاج إلى تثبيت أدوات البناء على جهاز المضيف (Ubuntu/Debian)
bash 
# تحديث القائمة وتثبيت أدوات البناء
sudo apt-get update
sudo apt-get install -y \
    debootstrap live-build xorriso squashfs-tools \
    grub-efi-amd64-bin grub-pc-bin syslinux \
    syslinux-common isolinux genisoimage dosfstools
02
تحميل سكريبت البناء
احفظ ملف bilal-os-build.sh في مجلد العمل وامنحه صلاحية التنفيذ
bash 
# انسخ السكريبت إلى مجلد العمل
mkdir -p ~/bilal-os
cp bilal-os-build.sh ~/bilal-os/
cd ~/bilal-os

# منح صلاحية التنفيذ
chmod +x bilal-os-build.sh
03
(اختياري) تخصيص الإعدادات
يمكنك تعديل المتغيرات في أعلى السكريبت قبل التشغيل
config 
OS_NAME="Bilal OS"       # اسم النظام
OS_VERSION="1.0"         # رقم الإصدار
OS_CODENAME="Horizon"   # اسم الإصدار
DEBIAN_SUITE="bookworm" # إصدار ديبيان
ARCH="amd64"             # المعمارية
TIMEZONE="Asia/Riyadh"  # المنطقة الزمنية
LOCALE="ar_SA.UTF-8"    # اللغة
USERNAME="bilal"         # اسم المستخدم
PASSWORD="bilal123"      # كلمة المرور
04
تشغيل البناء
شغّل السكريبت بصلاحيات root. سيقوم بكل شيء تلقائياً
bash 
# تشغيل السكريبت (يستغرق 30-90 دقيقة)
sudo bash bilal-os-build.sh

# ستجد الـ ISO النهائي في:
# ./bilal-os-output/bilal-os-1.0-amd64.iso
ℹ️ سيقوم السكريبت بمراحل: bootstrap ← تهيئة النظام ← تخصيص Bilal OS ← SquashFS ← Bootloader ← بناء ISO ← التحقق
05
اختبار الـ ISO في QEMU
اختبر النظام في محاكي افتراضي قبل الكتابة على USB
bash 
# تثبيت QEMU
sudo apt-get install -y qemu-system-x86

# تشغيل Bilal OS في QEMU (BIOS mode)
qemu-system-x86_64 \
  -m 2G \
  -cdrom bilal-os-output/bilal-os-1.0-amd64.iso \
  -boot d \
  -vga std

# تشغيل UEFI mode (يحتاج OVMF)
sudo apt-get install -y ovmf
qemu-system-x86_64 \
  -m 2G \
  -bios /usr/share/ovmf/OVMF.fd \
  -cdrom bilal-os-output/bilal-os-1.0-amd64.iso \
  -boot d
06
كتابة ISO على USB
كتابة الـ ISO على فلاشة USB لتشغيله على جهاز حقيقي
bash 
# اعثر على اسم الـ USB (احذر من الاختيار الخاطئ!)
lsblk

# اكتب الـ ISO على الـ USB (مثلاً /dev/sdb)
sudo dd \
  if=bilal-os-output/bilal-os-1.0-amd64.iso \
  of=/dev/sdX \
  bs=4M \
  status=progress \
  conv=fsync

# أو استخدم balenaEtcher (أسهل للمبتدئين)
⚠️ استبدل /dev/sdX باسم جهاز الـ USB الصحيح. سيمسح البيانات المخزنة عليه!
